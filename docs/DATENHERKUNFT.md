# Data provenance — foreign data that PrismLCA reads or derives from

A running register. **Every foreign data source that enters code, tables or tests gets a row here**:
where it comes from, under which licence, how we use it, and whether any of it lands in the repository
or in the build. The basic rule is BYOD (bring your own data): PrismLCA does not ship ecoinvent
nomenclature; whatever is licensed, the engine reads at runtime from the user's own copy.

## Rules

1. A new foreign source → a new row here, in the same commit as its use.
2. Whatever is read at runtime from an installed library (bw2io) is named as such in the code
   (provenance field on the object, path and package version in the log), so that a result can say
   later where its mapping came from.
3. Tables derived from licensed sources stay under `backend/local/` or `databases/`;
   `assets/` is build content.
4. The review table carries the rung (`rung`) on every row; the rung `ei2to3` **is** the provenance
   statement "ecoinvent correspondence via bw2io".
5. Fonts and airports are documented in detail in the notices next to their files
   (`assets/fonts/NOTICE.md`, `assets/transport/NOTICE.md`); the rows above only point to them.
